## Featured Projects

### [VolumeRecon](https://github.com/JayaChandraDadi/VolumeRecon)

**CT Image Reconstruction Pipeline**

Built an end-to-end reconstruction system that recovers 2D images and 3D volumes from simulated X-ray projection measurements.

* Generated configurable 2D phantoms and 3D volumes.
* Simulated projections from multiple rotation angles.
* Constructed sinograms and implemented filtered back projection.
* Added FFT-based filtering, post-processing, and error visualization.
* Evaluated reconstruction quality using RMSE, PSNR, SSIM, and relative L2 error.
* Implemented CPU and GPU execution using NumPy, SciPy, and PyTorch.
* Added automated tests, benchmarking, and interactive 3D visualization.

**Technologies:** `Python` `PyTorch` `NumPy` `SciPy` `scikit-image` `Matplotlib` `PyTest`

### [DefectVision](https://github.com/JayaChandraDadi/DefectVision)

**Industrial X-Ray Defect Detection**

Built an AI-assisted inspection system that identifies and localizes simulated internal defects in manufactured components.

* Generated synthetic plates, rings, and L-shaped components.
* Simulated X-ray attenuation, photon-counting noise, detector noise, and blur.
* Created void, crack, and inclusion defect classes.
* Generated pixel-level segmentation masks for model training.
* Implemented a multi-class U-Net using PyTorch.
* Compared baseline and augmented training pipelines.
* Added connected-component analysis and confidence-based inspection results.
* Built a Streamlit interface for reviewing masks, overlays, and reports.

**Technologies:** `Python` `PyTorch` `OpenCV` `Albumentations` `NumPy` `Streamlit`
